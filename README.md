## Tech

- **HTML5** + **CSS3** — no JavaScript, no dependencies
- **Inter** + **JetBrains Mono** (Google Fonts)
- Dark theme with indigo/cyan accents and glass morphism navigation
- Fully responsive (desktop, tablet, mobile)
- SVG favicon

## Run Locally

```bash
# Clone
git clone https://github.com/naveenkumarbaskaran/naveenkumarbaskaran.github.io.git
cd naveenkumarbaskaran.github.io

# Open in browser (macOS)
open index.html

# Or serve with Python
python3 -m http.server 8000
# → http://localhost:8000
```
